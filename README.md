# Thermal Printer Integration for Text Printing and Cutting

## Description

This project provides a Python utility for printing text and executing paper cutting commands on various thermal printers compatible with ESC/POS commands. It allows users to select from available printers, input text to print, and choose between full or partial cuts. The utility is designed for easy integration into point-of-sale systems and other applications requiring thermal printing functionality.

## Features

- List available thermal printers on the system.
- Select a printer for printing tasks.
- Input custom text to print.
- Send commands for full or partial paper cutting.
- Compatible with multiple thermal printer brands using ESC/POS commands.

## Requirements

- Python 3.12.x or latest
- `pywin32` library (for Windows)
